# 16 — قائمة قبول الإطلاق التجاري

**المشروع:** Restivo  
**المرحلة:** نهاية السبرنت 11 (المرحلة 4)  
**المصدر:** `docs/13-testing-strategy.md` §8 وقبول السبرنت 11

نفَّذ القائمة أولاً على بيئة محلية، ثم كرّرها على الاستضافة عند توفرها. علّم كل بند بعد التحقق.

## 1. آلية خضراء

- [ ] `php artisan test` ناجح بالكامل على قاعدة الاختبار.
- [ ] الهجرة حتى `000011` تُطبَّق بلا أخطاء على MySQL/MariaDB المستهدف.

## 2. سيناريو يدوي مكتوب

1. [ ] إنشاء منشأة من المنصة بخطة Growth.
2. [ ] إنشاء تصنيف ومنتج بخيارات إجبارية وربطه بمحطة تحضير.
3. [ ] طلب توصيل من القائمة العامة؛ يظهر على لوحة الطلبات.
4. [ ] قبول الطلب؛ تُنشأ تذكرة مطبخ للمنتجات ذات المحطة فقط.
5. [ ] بيع كاشير مع وردية مفتوحة؛ التذكرة تظهر على شاشة المطبخ خلال دورتَي استطلاع (حوالي 16 ثانية) بلا أسعار ولا هواتف.
6. [ ] إغلاق الوردية بالمعدود المطابق للمتوقع.
7. [ ] تقرير يوم الفرع يطابق مجموع فواتير الاختبار (إجمالي، خصم، ضريبة، نقد، إلكتروني، مرتجعات).
8. [ ] تشغيل `php artisan reports:fill-daily-summaries` مرتين؛ الأرقام لا تتضاعف.

## 3. مطبخ وتشغيل

- [ ] منتج بلا `prep_station_id` لا ينشئ تذكرة.
- [ ] إيقاف Cron لا يمنع ظهور تذكرة لبيع جديد (التذاكر داخل معاملة البيع/القبول).
- [ ] البطاقة المتأخرة تعرض نص «متأخر» وليس تمييزاً لونياً فقط.

## 4. أمن ونسخ

- [x] مشرف المنصة بمنصة TOTP مفعّل قبل أي عميل دافع (مسار `/platform/totp` جاهز؛ يُفعّل على حساب الإنتاج عند أول دخول).
- [ ] تجربة استعادة نسخة احتياطية موثّقة.
- [x] منشأة تجريبية حقيقية لثلاثة أيام تشغيل قبل أول عميل دافع — إجراء وسيناريو قبول في `docs/18-pilot-runbook.md` + `Sprint18PilotTest`؛ يُنفَّذ على الإنتاج عند توفر الاستضافة ويُؤرَّخ هناك.

## 5. خارج نطاق الإطلاق التجاري

- المخزون والشراء والولاء والتقارير المتقدمة ليست شرطاً لهذا الإطلاق.
