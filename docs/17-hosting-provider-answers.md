# 17 — إجابات مزوّد الاستضافة (P7-S17-01)

**المشروع:** Restivo  
**التاريخ:** 17 نوفمبر 2026  
**الحالة:** إجابات بيئة التطوير/التجريب المحلية مُثبَّتة أدناه. قبل أول رفع إنتاج يُستبدل عمود «الإنتاج» بإجابات المزوّد المكتوبة.

البنود الحرجة للإطلاق: CLI وCron وInnoDB وذاكرة ≥ 256M — يجب أن تكون **نعم**.
