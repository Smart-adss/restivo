# 18 — المراقبة اليومية أثناء التجريب (P7-S18-02)

## الأمر

```text
cd /home/{account}/restivo && /usr/local/bin/php artisan ops:health-check
```

يخرج بعدد `failed_jobs` وحجم `storage/logs` ومساحة القرص الحرة. رمز الخروج غير صفر إذا وُجدت مهام فاشلة أو امتلأ القرص تحت العتبة.

## القائمة اليومية (صباحاً Africa/Cairo)

- [ ] تشغيل `ops:health-check` — لا فشل صامت.
- [ ] فتح `/platform/failed-jobs` — كل صف مفهوم أو مُعاد بعد الإصلاح.
- [ ] مراجعة آخر سطور `storage/logs/laravel.log` لأخطاء 500.
- [ ] مساحة القرص من cPanel أو من خرج الأمر ≥ 1 GB حر (أو عتبة المزوّد).
- [ ] Cron الدقيقة ظاهر في `logs/schedule.log` خلال الساعة الماضية.
- [ ] عامل الطابور `--stop-when-empty` يفرّغ `jobs` بعد البريد التجريبي.

## تفسير سريع

| الإشارة | المعنى | الإجراء |
|---|---|---|
| `failed_jobs` > 0 | مهمة بريد/وصفة/ملخص فشلت | اقرأ الاستثناء من الشاشة؛ أصلح السبب؛ احذف الصف بعد التحقق أو أعد المحاولة يدوياً |
| سجل ينمو بسرعة | حلقة أخطاء | أوقف Cron مؤقتاً إن لزم؛ راجع آخر stack |
| قرص منخفض | وسائط أو سجلات | فرّغ سجلات قديمة؛ لا تحذف `storage/app` عشوائياً |

لا اعتماد على New Relic في الإطلاق. المرجع: الأمر + الشاشة + cPanel.
