# 18 — تجريب منشأة على الإنتاج (P7-S18-01 / P7-S18-03)

**الهدف:** ثلاثة أيام تشغيل حقيقية قبل أي عميل دافع. لا ميزات جديدة أثناء التجريب — إصلاح عيوب القبول فقط.

## يوم 0 — إنشاء المنشأة التجريبية

1. مشرف المنصة (بعد TOTP) ينشئ منشأة بخطة Growth واسم واضح مثل `pilot-cairo`.
2. تسليم كلمة مرور المالك المؤقتة عبر مدير كلمات مرور (انظر `18-owner-training.md`).
3. المالك يغيّر كلمة المرور فوراً.
4. إنشاء تصنيف + منتج واحد على الأقل + تفعيل الطلب العام والحجز إن لزم من الخطة.
5. ربط منتج بمحطة تحضير إن كان المطبخ ضمن نطاق التجريب.
6. فتح صندوق نقدي للفرع.

## سيناريو القبول (يُعاد يومياً أو بعد كل إصلاح)

| # | الخطوة | معيار النجاح |
|---|---|---|
| 1 | بيع كاشير مع وردية مفتوحة | فاتورة مكتملة برقم وإجمالي |
| 2 | طلب عام (استلام) من القائمة | يظهر على لوحة الطلبات |
| 3 | حجز عام أو من الموظف | صف في الحجوزات لليوم |
| 4 | إغلاق الوردية بالمعدود المطابق | فرق = 0 |

أمر التحقق الآلي محلياً قبل/بعد الإصلاحات:

```text
php artisan test --filter=Sprint18PilotTest
```

## أيام 1–3

- كل صباح: `php artisan ops:health-check` ثم مراجعة الشاشة `/platform/failed-jobs`.
- تسجيل أي عيب في جدول أسفل هذا الملف؛ الإصلاح بلا فتح ميزات.
- بعد الإصلاح: إعادة سيناريو القبول كاملاً.
